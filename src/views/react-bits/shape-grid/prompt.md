# ShapeGrid — React Bits

## Source
- Component: ShapeGrid from React Bits library
- Variant: JavaScript + CSS

## Props
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| direction | string | 'right' | Animation direction: diagonal/up/right/down/left |
| speed | number | 1 | Animation speed multiplier |
| borderColor | string | '#999' | Grid tile border color |
| squareSize | number | 40 | Tile size in pixels |
| hoverFillColor | string | '#222' | Fill on hover |
| shape | string | 'square' | Tile shape: square/hexagon/circle/triangle |
| hoverTrailAmount | number | 0 | Trail length (0 = no trail) |

## Files
- ShapeGrid.tsx — Core canvas component
- ShapeGrid.css — Component styles
- ShapeGridPage.tsx — Interactive demo page with controls
